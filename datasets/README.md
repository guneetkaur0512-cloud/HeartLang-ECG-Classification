# Dataset Note

The PTB-XL dataset and generated NumPy arrays are not included in this GitHub repository because of file-size constraints.

The experiments used the PTB-XL Superdiagnostic task with:

- Training samples: 17,084
- Validation samples: 2,146
- Test samples: 2,158

The final proposed method used preprocessed QRS-tokenized data generated from the PTB-XL Superdiagnostic split.

Large files excluded from GitHub include:

- raw PTB-XL WFDB records
- `*.npy` processed arrays
- `*.pth` trained checkpoints
- archive backups such as `*.tar.gz`

These files can be shared separately through external storage if required.
